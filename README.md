# Cursor fast proxy

Приложение для macOS. Оно направляет облачный трафик Cursor через один VPS, который пользователь сам указал в настройках.

Исходный код здесь не публикуется. Сборки лежат в [релизах](https://github.com/vivaladev/cursor-fast-proxy-releases/releases).

## Цель

Cursor должен ходить в своё облако не напрямую с Mac, а через свой VPS. Остальной трафик компьютера, включая рабочие VPN, приложение не перехватывает.

## Как это работает

1. В настройках сохраняются адрес, пользователь и пароль одного VPS.
2. Кнопка «Вжух и прокси» ставит на этот VPS единственный вход для Cursor и поднимает на Mac локальный прокси `127.0.0.1:18081`.
3. Cursor отправляет на этот локальный адрес только свой облачный трафик.
4. Локальный sing-box забирает его и уводит на настроенный VPS. Дальше в интернет трафик выходит уже с VPS.

Таблица маршрутов Mac не меняется. Отдельного туннеля на всю систему нет.

## Только настроенный VPS

Приложение не подключается ни к какому другому серверу.

В нём нет встроенных адресов, публичных прокси, списка запасных узлов и автоматического выбора хоста. Пока в настройках не сохранён свой VPS, цепочка не запускается. После сохранения весь прокси-трафик Cursor идёт только на этот адрес. Сменить сервер можно лишь одним способом: удалить текущие настройки прокси, записать другой VPS и нажать «Вжух и прокси» снова.

## Установка

1. Скачай `Cursor-fast-proxy-1.1.0-mac.zip` из [релизов](https://github.com/vivaladev/cursor-fast-proxy-releases/releases).
2. Распакуй архив и перенеси `Cursor fast proxy.app` в «Программы».
3. При первом запуске macOS может спросить разрешение: в «Настройках системы → Конфиденциальность и безопасность» нажми «Всё равно открыть».

В архиве `agent-docs-1.1.0.zip` лежит документация для агента.

В приложении нет чужих адресов, логинов и паролей. Их вводят в «Настройках» на своём Mac.
