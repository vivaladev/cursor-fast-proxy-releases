# Cursor fast proxy

Публичные загрузки приложения. Исходный код здесь не публикуется.

## Установка

1. Открой [релизы](https://github.com/vivaladev/cursor-fast-proxy-releases/releases).
2. Скачай `Cursor-fast-proxy-1.1.0-mac.zip`.
3. Распакуй архив и перенеси `Cursor fast proxy.app` в «Программы».
4. При первом запуске macOS может спросить разрешение на приложение от неизвестного разработчика: в «Настройках системы → Конфиденциальность и безопасность» нажми «Всё равно открыть».

В архиве `agent-docs-1.1.0.zip` лежит документация для агента: как устроен прокси, что трогать в коде и чего не делать.

В приложении нет чужих адресов, логинов и паролей. Их вводят в «Настройках» на своём Mac.
